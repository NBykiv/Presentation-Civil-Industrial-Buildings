# 🏢 Презентація "Цивільні і промислові будівлі"

Інтерактивна веб-презентація з 13 слайдами для дисципліни **"Вступ до будівельної справи"** напряму **6.060101 "Будівництво"**.

---

## 📋 Зміст презентації

### Слайди:
1. **Титульна сторінка** — Вступна інформація та назва
2. **Мета та задачи** — Цілі дисципліни
3. **Основні поняття** — Визначення будівель та споруд
4. **Цивільні будівлі** — Типи та вимоги
5. **Промислові будівлі** — Типи та особливості
6. **Класифікація за капітальністю** — 4 ступені капітальності
7. **Класифікація за матеріалами та висотою** — Матеріали конструкцій та висотна класифікація
8. **Вогнестійкість** — Класифікація матеріалів та конструкцій
9. **Експлуатаційні вимоги** — 6 основних вимог до будівель
10. **Технічні вимоги** — Вимоги до конструкцій
11. **Нормативно-правова база** — ДБН, ДСТУ, технічні регламенти
12. **Ключові висновки** — Основні напрацювання
13. **Рекомендовані джерела** — Нормативні документи та література

## 🚀 Як використовувати

### Спосіб 1: Локальне відкриття
1. Клонуйте репозиторій:
```bash
git clone https://github.com/NBykiv/Presentation-Civil-Industrial-Buildings.git
cd Presentation-Civil-Industrial-Buildings
```

2. Відкрийте файл `index.html` у браузері:
```bash
# На Windows
start index.html

# На macOS
open index.html

# На Linux
xdg-open index.html
```

### Спосіб 2: GitHub Pages (якщо ввімкнено)
Перейдіть за посиланням (коли GitHub Pages активовано в налаштуваннях репозиторію)

## 💡 Приклади вмісту

### Класифікація за капітальністю:
- **І ступінь**: постійні будівлі на 50+ років з усіма інженерними системами
- **ІІ ступінь**: постійні на 20-50 років з основними системами
- **ІІІ ступінь**: тимчасові на 5-20 років
- **IV ступінь**: тимчасові на 1-5 років з мінімальними вимогами

- 🌱 Екологічність
